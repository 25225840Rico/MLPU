# 2026-07-16 — Sesión 14: post-mortem duplicados IG + fix anti-duplicación

## Reporte del usuario
"Ayer intenté publicar varios y no se pudo, se repetían." Pidió: más simple pero
igual de funcional, foco en IG, más robusto, mejor organizado.

## Evidencia (D1 remota + Graph API /media)

- 8 publicaciones entre 02:08 y 02:43 UTC (22:08–22:43 Chile) → varias corridas

- **Nissan GT-R (id 10) y Mazda RX-7 (id 11)**: el media_id del feed real ≠ el

- **Dodge Viper (id 12)**: publicado en el feed (02:43:07, media 18156971635487384)

- Tundra (id 4): DB dice publicado 02:08 pero no está en el feed (borrado a mano).

## Causas raíz (3)
1. **Sin idempotencia feed/historia**: la fila se marcaba `publicado` solo si
   feed Y historia salían. Historia fallaba ("Media ID is not available") → fila
   quedaba `pendiente` → el reintento volvía a subir el MISMO feed (hasta 3 veces).
2. **Sin lock ni claim**: /ig ahora corre en background (waitUntil); mandarlo dos
   veces (o cruzarse con el cron) hacía que dos corridas leyeran las mismas filas
   pendientes y publicaran duplicado. Si el Worker moría después del feed y antes
   del UPDATE, la fila quedaba `pendiente` con el post ya en IG (caso Viper).
3. **Poll insuficiente**: waitForContainer esperaba máx 15 s (25×600 ms); las
   imágenes compuestas (blur 1080×1920) tardan más → media_publish con el
   contenedor aún procesándose → "Media ID is not available".

## Fix (commit cd8d257, deploy 0d4712e2)
- `claimNext`: UPDATE…RETURNING atómico → estado `publicando` + intentos+1 +
  `claimed_en` (columna nueva, ALTER aplicado en remote).
- Feed idempotente: `ig_media_id` se guarda apenas sale; reintento lo salta.
- Historia best-effort: si falla, fila `publicado` + ultimo_error='historia: …'
  + aviso por Telegram ("solo feed"). Nunca más repite el feed.
- `recoverStuck`: `publicando` > 15 min → `pendiente` (sin repetir el feed).
- Lock consultivo `ig_config.corriendo` (TTL 10 min): segundo /ig ahora responde
  "ya hay una publicación en curso". El claim por fila es la garantía dura.
- Poll de Meta: 30×2 s (~60 s) + reintentos con base 3 s.
- `/ig ahora [n]`: publica hasta n (1-10, default 3).
