3) Alcance: 4 frentes en fases: F0 bootstrap (credenciales, sync catalogo,
   config inicial) -> F1 Collector+D1+tablero KPIs Telegram (solo lectura)
   -> F2 competencia+score+propuestas precio+applier+monitor+rollback
   (100% deterministico, sin LLM) -> F3 SEO/calidad fichas (UNICO modulo
   con LLM, Haiku) -> F4 rotacion/inventario+experimentos A/B.
4) Ritmo/costo: ciclo diario nocturno (cron cada 15 min ventana 02:00-06:00,
   lotes ~30 items por limite de 50 subrequests/invocacion, patron
   Job->Batch->Item con reintento por batch). Presupuesto LLM < US$3/mes
   con auto-apagado por flag. Infra US$0 hasta ~5.000 items.
5) Modelo de datos D1 aprobado (con ajustes del usuario): listings,
   listing_snapshots (snapshot_at UTC timestamp, + buy_box_price,
   listing_type, shipping_mode), competitor_snapshots (agregados diarios
   + sample_size, category_id, top5_json), orders, opportunities (score,
   expected_gain, confidence, priority), proposals (payload_json +
   estimated_impact_json, absorbe approvals, tg_message_id, expiran 72h),
   changes (before_json completo = rollback; verified_at,
   verification_status: verified/pending/failed/timeout; NUNCA se borra),
   experiments, jobs, job_batches, events (event store de dominio:
   PRICE_CHANGED, PROPOSAL_APPROVED, etc., poda 180d), feature_flags,
   system_metrics (salud: api_calls, errores, cron_duration, llm_cost...).
   Todas las tablas llevan seller_id (multi-tenant). Normalizer separado
   del Collector; el raw de ML NO se persiste.
6) Guardrails aprobados: MAX_PRICE_DELTA_PCT +-10%, cooldown 7 dias/item,
   min_price por item (default -25%), terminacion 990/989, REGLA DEL
   UMBRAL $19.990 (cruzarlo cuantifica el efecto envio gratis obligatorio
   ~$6.300/venta en estimated_impact_json; umbral en config), under_review/
   sub_status intocables, variaciones via variations:[{id,price}],
   KILL_SWITCH y DRY_RUN por flag, verificacion por relectura post-PUT,
   abortar batch tras 3 fallas, circuit breaker global (5xx -> KILL_SWITCH
   + aviso), MIN_BASELINE_VISITS (default 50) para rollback automatico
   (bajo eso solo alerta con boton Revertir), MAX_ACTIVE_OBSERVATIONS=10,
   manual_override=true 7 dias si el Collector detecta cambio manual
   (estado real != ultimo after_json nuestro). Rollback automatico SOLO
   precio (visitas caen >40% vs baseline 14d con muestra suficiente);
   ventana de observacion 7 dias; Monitor escribe impacto real vs estimado.
7) Costos validados por escala (100/500/1000/5000): US$0 infra hasta 5.000
   items (a 5.000: ampliar ventana cron o Workers Paid US$5/mes opcional);
   LLM ~US$0.2-3/mes. Cuello real: ventana horaria del cron a 3-5k items.
